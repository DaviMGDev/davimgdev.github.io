01 // quem somos

Uma empresa que funciona como um projeto bem documentado: todo mundo contribui, e nada fica sem registro.

Somos o laboratório onde estudantes de Engenharia de Computação da UEFS aprendem o ofício fazendo — e onde micro e pequenas empresas encontram tecnologia sob medida, sem burocracia de agência.

Nós somos uma Empresa Júnior de Engenharia de Computação, composta por alunos da Universidade Estadual de Feira de Santana. Promovemos impactos positivos em micro e pequenas empresas por meio de soluções tecnológicas. Fundada em 2007, a EcompJr atualmente participa ativamente do propósito que envolve ser Movimento Empresa Júnior.

02 // o que fazemos

Quatro módulos prontos para deploy.

Da página institucional ao sistema de gestão: escolha o módulo e a gente faz o build. Cada serviço é desenhado para eliminar gargalos operacionais e impulsionar o crescimento da sua empresa.

módulos disponíveis

modulo: sites-estaticos tipo: estático

static site -> pagina personalizada

Projeto de um site estático personalizado. Consistindo em páginas web fixas, que não possuem conexão com banco de dados e não são alteradas pelo usuário.

site no ar, responsivo e funcional

quero esse módulo ->
modulo: sites-dinamicos tipo: dinâmico

dynamic site -> conteudo editavel + banco de dados

Websites personalizados e que podem ter seu conteúdo alterado pelo contratante. Como jornais, blogs ou revistas onlines com publicações. Possuem uma conexão com banco de dados para modificar as páginas.

site com publicação própria do contratante

quero esse módulo ->
modulo: sistemas-web tipo: gestão

web system -> gestao interna no navegador

Sistema utilizado através de um navegador para gestão interna e gerência de informações. Esse sistema possui um servidor na rede, local ou não, para seu funcionamento.

sistema de gestão acessível de qualquer lugar

quero esse módulo ->
modulo: eventos-virtuais tipo: ao vivo

live event -> transmissao assistida + certificados

Assistência em Eventos Virtuais, com monitores que auxiliam nas transmissões. Coordenando e gerenciando as salas, além de emitir e enviar os certificados.

transmissão coordenada e certificados emitidos
